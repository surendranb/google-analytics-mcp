3. Ephemeral OAuth Authorization Relay

For developer convenience, GA4 MCP operates an ephemeral Cloudflare Edge gateway to facilitate browser-based Google OAuth token exchange.

  • The authorization relay is provided free of charge for individual developers and organizations.
  • The relay acts strictly as a stateless pass-through; credentials and tokens are returned immediately to your local machine and never persisted in server databases.
  • You may bypass the authorization relay entirely at any time by configuring your own Google Cloud Service Account key (GOOGLE_APPLICATION_CREDENTIALS) or local Application Default Credentials (ADC).
