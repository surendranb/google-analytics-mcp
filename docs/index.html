Security & Compliance

Zero-Knowledge Security Architecture

Your analytics metrics and credentials never touch our servers. Designed for engineering leaders who require mathematical privacy guarantees.

Zero Server Retention

The ephemeral Cloudflare Edge gateway serves solely as an authorization relay. Refresh tokens and query data are never saved to any database, cache, or log. Tokens live exclusively on your machine.

Read-Only Scope Protection

Authentication is mathematically confined to analytics.readonly. The agent is structurally incapable of altering settings, deleting events, or making unauthorized configuration changes.

Direct-to-Google Queries

Once authenticated, your local IDE queries Google's official Data API (analyticsdata.googleapis.com) directly over TLS. Zero analytics traffic ever transits our gateway.

Universal IDE Support

Configure Any AI Agent in Seconds

Compatible with all Model Context Protocol clients. Select your environment below for the exact configuration snippet.

Claude Code (Anthropic Terminal Agent): Run this command directly in your terminal to add GA4 MCP globally:

Terminal Command 
claude mcp add google-analytics -- uvx google-analytics-mcp

Claude Code will automatically download and run the server using uvx. When prompted for analytics queries, it will trigger the browser login if no credentials exist.

Cursor IDE: Add this to your project root in .cursor/mcp.json (or global Cursor MCP settings):

.cursor/mcp.json

Developer Reference

Schema Resilience & Troubleshooting

GA4 MCP includes built-in case-translation and automatic recovery logic to ensure your agent never gets stuck.

1. Case-Resilient Filter Formatting (camelCase & snake_case)

The GA4 MCP server automatically translates all filter parameters. Your AI agent can generate either standard Google Analytics API format (fieldName, stringFilter, andGroup) or Pythonic format (field_name, string_filter, and_group). Both compile and execute identically.

2. Combining Multiple Filters (andGroup / orGroup)

To combine multiple conditions (e.g. city is London AND device is Mobile), the filter must use an andGroup containing an expressions array. The MCP server validates this structure automatically before making the network request to prevent 400 Bad Request errors.

3. How to fix IAM Permission Errors with Service Accounts

If using a service account JSON file and receiving IAM Error: The service account does not have Viewer access: Open analytics.google.com → Admin → Property Access Management → Click + (Add users) → Paste your service account email (...iam.gserviceaccount.com) → Assign Viewer role.

4. Refreshing Expired Application Default Credentials (ADC)

If using local gcloud CLI authentication and receiving a 503 Reauthentication error, your local token has expired. Run gcloud auth application-default login in your terminal to refresh it.
